# Project Intake

1. Read existing project state, repo instructions and evidence before asking questions.
2. Restate the goal as observable outcomes, not implementation jargon.
3. Identify target platform, artifact/repo, constraints, current failure, and what "working" must visibly do.
4. Ask only for a true blocker: missing authorization, credential, target, required physical action, or mutually exclusive output choice.
5. Otherwise choose the least-complex safe default and begin.
6. Write/update `.agent/PROJECT_STATE.md` with: Goal, Current State, Acceptance Criteria, Constraints, Active Profile, Next Gate.
7. Keep active goals to three or fewer.
