# daveai-windows-app-e2e

**Use when:** working with a Win32, UWP, or .NET Windows application

## Steps
- Identify the build system: MSBuild, dotnet, or WinApp CLI.
- Build the app and record the command/output.
- Automate the critical UI flow with WinApp CLI + win-dev-skills or Playwright.
- Run the flow, capture a screenshot or accessibility snapshot.
- Record the version, build command, and test result in the ledger.

## Proof required
build log and UI flow screenshot/accessibility snapshot
