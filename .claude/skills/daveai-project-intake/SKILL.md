# daveai-project-intake

**Use when:** starting a new task or entering a new project workspace

## Steps
- Capture the user goal in one plain-language sentence.
- Identify the target artifact(s), workspace, and any sensitive data.
- Select the smallest DAVE-AI profile that can solve the task.
- Write AUTHORIZED_SCOPE.md with the allowed tools and forbidden actions.
- Record the plan and gate acceptance criteria in PROJECT_STATE.md.

## Proof required
PROJECT_STATE.md and AUTHORIZED_SCOPE.md with task, profile, and gates
